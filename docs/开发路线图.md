## 分工原则

- **DS** 做阶段 5 里只加数据、不改代码的部分（支线、NPC 事件链、营地事件），在 `ds-content` 分支上做，Claude 审核后合并。任务书是 `docs/任务书-内容扩充-DS.md`。

- **Claude** 做系统和代码（数据结构、战斗、校验、界面），以及剧情锚点的主体。
- **GPT/Codex** 做真实模型试玩和验收、立绘（图片生成）、大批量的文字素材初稿，比如营地事件、支线的 hook，由 Claude 审过再并入。
- 两边同时干活时，**GPT 在隔离的 worktree 里测某个固定提交**，Claude 在主工作区开发；`HANDOFF.md` 冲突时两边都保留。
- 每一阶段做完：语法检查、`tests/game-logic.test.mjs`、`tests/local-server.test.mjs`、战斗模拟（如果改了战斗），浏览器用假说书人走一遍；提交和推送前先问用户；推送后同步 claude.ai 页面。

### 阶段 2：印记与龙化（Claude，M）

这是本作的特色机制（设定集“印记系统”），现在龙化值只是一个数字。

- [x] 龙化值解锁印记能力，每场每种一次：龙之眼、龙息、龙威、龙翼（`MARKS`）
- [x] 同伴也有龙化值（进入第二、三幕各 +15），自动战斗会用龙之眼和龙息
- [x] 印记共鸣：赞同度到 40 后营地里一次共鸣，解锁合体技（`COMBOS`）
- [x] 龙化值影响同伴态度：跨过 40 / 60 / 80 时按 `DRAGON_VIEW` 调赞同度，看法写进同伴资料
- [x] 侧栏和说书人提示里显示龙化值和解锁情况
- 验收：自动测试 + 模拟（用了印记能力的队伍胜率变化）
