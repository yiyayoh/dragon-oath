# 开发路线图

写于 2026-10-28，Claude 写。记录从“故事能从头玩到尾”到“设定集里的完整版”还要做的事，以及先后顺序。Claude 和 GPT/Codex 都按这份来，做完一项就在这里打勾，并在 `HANDOFF.md` 开发记录里补一行。

## 现状（10-28）

- **能玩**：序幕和三幕都有了，结尾有七种结局。一共 54 个场景、19 个支线、58 个营地事件。系统有区域制战斗（含 Boss 机制）、1～12 级、营地与恋爱、个人任务、三层记忆、存档。
- **时长**：粗估 8～12 小时，设定集目标是 18～24 小时。GPT 正在按 `docs/任务书-扩充内容验收.md` 实测。
- **没用真实模型玩过的**：第二幕、第三幕、结局，以及第一轮扩充的内容。

## 分工原则

- **Claude** 做系统和代码（数据结构、战斗、校验、界面），以及剧情锚点的主体。
- **GPT/Codex** 做真实模型试玩和验收、立绘（图片生成）、大批量的文字素材初稿，比如营地事件、支线的 hook，由 Claude 审过再并入。
- 两边同时干活时，**GPT 在隔离的 worktree 里测某个固定提交**，Claude 在主工作区开发；`HANDOFF.md` 冲突时两边都保留。
- 每一阶段做完：语法检查、`tests/game-logic.test.mjs`、`tests/local-server.test.mjs`、战斗模拟（如果改了战斗），浏览器用假说书人走一遍；提交和推送前先问用户；推送后同步 claude.ai 页面。

### 阶段 1：装备、商店、战利品（Claude，M）

现在物品只是字符串，探索拿不到实在的东西。BG3 的乐趣有一大块在“搜刮”。

- [x] 物品表 `ITEMS`：约 35 件，武器、护甲、饰品、消耗品（护甲和饰品做成“在原数值上加”，不重算基础 AC）
- [x] 装备栏：近战、远程、护甲、饰品两件；角色卡里换装，同伴也能换；战斗数值从装备算
- [x] 消耗品：战斗中喝药（附赠动作）、扔炸弹和卷轴（动作，选区域），同伴低血自己喝药；战斗外在角色卡里喝
- [x] 商店：5 家（鱼市、赌场黑市、船上补给、潮裔、避难所黑市）；阵营声望影响价格留到阶段 4
- [x] 战利品：`LOOT` 每场遭遇打赢后发一次；支线奖励的物品都在表里；说书人给的 `rare` 物品要锚点里写着才算
- [x] 旧存档不用迁移：字符串物品照旧是杂物，名字在表里的自动变成真物品
- [ ] 模拟器给队伍配推荐装备重跑平衡（和阶段 3 一起做）

### 阶段 2：印记与龙化（Claude，M）

这是本作的特色机制（设定集“印记系统”），现在龙化值只是一个数字。

- [x] 龙化值解锁印记能力，每场每种一次：龙之眼、龙息、龙威、龙翼（`MARKS`）
- [x] 同伴也有龙化值（进入第二、三幕各 +15），自动战斗会用龙之眼和龙息
- [x] 印记共鸣：赞同度到 40 后营地里一次共鸣，解锁合体技（`COMBOS`）
- [x] 龙化值影响同伴态度：跨过 40 / 60 / 80 时按 `DRAGON_VIEW` 调赞同度，看法写进同伴资料
- [x] 侧栏和说书人提示里显示龙化值和解锁情况
- 验收：自动测试 + 模拟（用了印记能力的队伍胜率变化）

### 阶段 3：职业成长与同伴专属技能（Claude，M）

现在 6 级以上升级只加生命和熟练加值。

- [ ] 六个职业在 6、7、9、11 级各有新能力（例如圣武士的守护灵光、游荡者的反射闪避、法师的三环法术、牧师的引导神力加强）
- [ ] 同伴专属技能（设定集角色卡）：赛勒涅的圣疗、维克斯的诡计、卡西安的祈福术、博林的狂战怒吼、莉拉的奥术爆发、奈雅的形变
- [ ] 短休：营地之外可以短休一次（花时间，恢复部分技能），长休恢复全部
- [ ] 可选：手动指挥同伴（战斗设置里开关）
- 验收：自动测试 + 第二、三幕重跑模拟（现在胜率接近 100%，加强玩家后要同步加强敌人，目标胜率 85～95%）

## 建议的顺序

1. **现在**：GPT 做阶段 0 的实测；Claude 开始阶段 1（装备）。装备改的是物品和战斗数值，和 GPT 测的剧情流程不冲突。
2. GPT 报告回来后，Claude 先修报告里的问题（阶段 0），再继续阶段 1。
3. 阶段 2（印记）→ 阶段 3（职业）→ 阶段 4（声望）。阶段 3 做完后统一重调第二、三幕的战斗平衡。
4. 阶段 5（内容第二轮）贯穿进行；GPT 有空就做阶段 7（立绘）。
5. 阶段 6 放在阶段 3 之后，阶段 8 放在最后。
