# 长期角色档案与当前重点

2026-11-04；开发基线main 3f1a488。本批尚未提交推送。开发和测试均使用隔离源代码副本、新浏览器与随机端口；未读取或修改主目录个人存档，未操作8787。

## 改变后的行为

原先每人最多10条，后台把模型返回的最多8条覆盖旧列表。现在memory.people作为长期档案保存，只有完全相同的条目去重，后台不再覆盖或按数量删旧事。peopleFocus只表示整理模型挑选的近期重点；peopleMeta保存类别、提醒状态、重点、场景和可验证的原文出处。既有程序明确撤销错误记录时仍允许纠错。

每轮按当前对话、在场角色、未完承诺和矛盾、手动重点及关联词选择。每人最多10条，普通6500、战况2200、整理4500字符的全局选择预算，另加简短说明。选择过程不修改存档；未取出的内容仍在完整日志与长期档案，可按话题再次检索。后台重点必须照录已有条目，新摘录须是剧情中实际出现的连续原句，并有角色知情证据。

新原文记录当时的知情同伴；单独夜谈只记对应角色，双人场景按实际在场角色记录。引用缺席同伴过去的台词不会赋予其本次知情。NPC本人明确说出的台词可作为本人的出处；旧原文没有可靠归属时不猜测。

日志和角色卡显示档案总数、当前重点，可展开全部；各条可查看出处、设重点、标为已解决或被后续取代，也可恢复提醒。这些按钮仅调整记忆提醒，不改变任务标记、赞同或关系。

## 存档与旧事

旧memory.people仍然兼容，迁移不修改传入对象或剧情原文。旧条目缺乏出处时明确显示未定位，不补造场景。首次迁移从原文里保守提取本人的重要台词；后台可逐批摘录有知情证据的新原文。失败、中断、问句、假设、伪造引文不归档，不能把玩家读过的内容当成所有同伴都读过。已被旧版丢弃且没有可靠原文证据的条目不会凭空恢复。

新增可选字段peopleMeta、peopleFocus、peopleVersion有结构验证；当前档案随自动/手动档、导出和硬盘备份保存。整理期间新增记忆继续保留；换局或读档后的迟到后台结果和调用记录不写入新局。

## 实际边界

长期档案不再由摘要淘汰，仍不等于模型每轮都主动提起全部往事。上下文有预算，未完承诺优先取出；真实模型对提示词的遵守仍取决于模型。提醒解决或取代状态提供原生确认入口，不根据模糊文本自动结算。完全相同的内容去重，相近但不同的表达可能并存；可用取代状态保留历史并停止旧提醒。
