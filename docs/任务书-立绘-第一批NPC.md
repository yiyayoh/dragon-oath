## 规格（和以前一样，见 `HANDOFF.md` 的“立绘”一节）

1. 生成 1024×1536 的原图（PNG），存在工作区外面，比如桌面上新建 `dragon-oath-portraits-v4`。原图里把用的提示词也记下来（一个 `prompts.md`）。
2. 转成 768×1152 的 webp：

   ```bash
   cwebp -q 84 -resize 768 1152 原图.png -o eel_neutral.webp
   ```

   每张大约 70～190 KB。
3. 放进**你自己的隔离副本**的 `portraits/` 里（不要放进主工作区），用浏览器打开副本，进到对应 NPC 出场的地方看一眼：舞台上的立绘有没有正常显示、裁切有没有问题（头顶留白、脸不要被裁掉）。测试存档 `tests/saves/03-总督府-正式请柬.json` 里能见到总督和萨丝，`02-金鳗货舱-救莉丝.json` 附近的赌场能见到老鳗。
