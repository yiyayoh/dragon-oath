# 记忆、日志与第一幕优化记录

2026-11-03；源码基线 `0e2e724`。全部开发、接口与浏览器测试使用隔离副本与随机端口，没有读取或改动主目录个人存档，没有操作8787或个人浏览器。本批纳入11-03统一提交，版本见Git历史与HANDOFF。

## 交付功能

- 长期纪要与剧情原文完整保留；普通回合按本轮话题检索完整纪要，优先最近三章与相关旧事，再带未选篇章的标题索引。普通纪要目标9000字符，战况/整理记忆目标5000字符；这不是整轮提示的总长度。
- 有出处的记事：`memory.facts`保存承诺、已读和线索的原文摘句、相关主体、场景与来源位置。说书人只能提交当轮正文或玩家原话中的连续引用，不能靠新字段直接改任务状态。已读摘记必须由GM正文明确确认相应主体完成阅读，拒绝否定、提问与准备动作；NPC摘记需要明确姓名，玩家自述不记到NPC名下。旧档保守扫描已有原文，失败和中断条目不进入记事；不会补造旧选择。
- 日志搜索覆盖纪要、人物记忆、记事、任务与剧情/战斗原文；支持空格分隔多个关键词。失败、正在生成的内容明确标注；不把GM锚点与未发现秘密塞进搜索结果。重要记事可设为重点并随档保存，优先用于回忆。
- 手动存档命名最多40字；只改所选存档名称，不用当前角色覆盖原档。名称跟随硬盘、备份和版本校验保存；旧客户端遗漏名称时服务保留原名。过期命名另存冲突副本，不覆盖较新档。
- 第一幕按真实标记显示钥匙、航海图和船的进度与下一步。准备齐全时，可原生返回酒馆、扎营继续主线；仍允许继续支线，不自动跳过夜谈或灯塔。
- 普通地点可以在同一轮经港口街前往另一个普通地点，减少来回问目的地。未完成检定、战斗与特殊剧情不开放这条捷径；不能绕过灯塔条件或舞会请柬。
- 修正地点识别：人在金库时，“总督府地下楼梯”不会因为包含总督府三字就退回入口；未结束检定时不根据地点文字自动转场。
- 真实借船流程暴露模型把海鸥号写成未支持的watch或误记为hired；第一幕每轮提示现在直接列出关键标记的合法值与船名映射，不再仅依赖当前场景的锚点。
