# 存档与异常回复修复记录

2026-11-01。用户要求立即修复独立复查发现的全部六项问题。开发、浏览器测试和服务写盘使用隔离目录与临时端口，未读取或修改个人存档。

| 问题 | 修复后的行为 |
| --- | --- |
| 全局检查点串到另一个角色 | 新局带独立 runId，只接受同局检查点；检查点随存档写盘、导出，重复取点不递归嵌套。 |
| 缺失、损坏、截断 JSON 被当成成功 | 普通剧情和即兴回复先校验正文与 JSON，再应用变更；失败不增轮、不清重试。战斗纯叙述仍可不带 JSON。 |
| 中断的正文被记进后续剧情 | 失败玩家行动与正文均标未完成；排除近期上下文、原文找回、成功检定后续与章节纪要来源。 |
| 读取手动档或备份后刷新回到旧自动档 | 成功读档、导入后立即保存自动档。读档列表先刷新，避免异步重画移除导入确认。 |
| 损坏导入先覆盖状态再报错 | 在替换前校验必需字段；迁移或渲染异常时恢复原状态。旧档缺后来加入的同伴仍自动补齐。 |
| 旧页面覆盖新的硬盘进度 | 服务串行核对 expectedRevision，过期写入返回 409；页面保留冲突副本，用户可在存档菜单选择。相同内容重传幂等；刷新时保留版本标记。 |

验证结果：

- 游戏逻辑 73 项、本地服务 16 项，共 89 项通过。
- 浏览器实测：手动读档后刷新；跨角色不显示错误重试；检查点随文件导入并重试、刷新；坏档拒绝；不同浏览器和同浏览器多页竞争写入；冲突副本在刷新后保留，明确恢复后再次刷新保持选中进度。无页面脚本错误。
- 35 组战斗条件，每组 300 局；结果与修复前数值一致。
- 旧版九份测试存档与新版生成九份均验证可加载；网页脚本、本机服务语法检查通过。

兼容和使用：旧存档不强制改写格式；局标识会在加载时补齐。旧全局检查点没有可靠的局归属时不再复用。冲突副本在当前浏览器，清理浏览器数据前应先读取并导出。本轮未重跑真实模型长局，也未扩大设计规则。

应用新版时，关闭本机游戏服务窗口，重新双击“开始游玩.cmd”，再刷新游戏页面。主目录源码已更新，未提交、推送、发布或替换旧同步包。
