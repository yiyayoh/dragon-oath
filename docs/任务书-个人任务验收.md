## 背景

`380d997` 加了个人任务：每位同伴两步 + 一个抉择 + 恋爱的“考验”，数据在 `QUESTS`。代码管：

- 按顺序推进（跳步的标记会被丢弃）；
- 第一步之后要这个同伴赞同度 ≥ 20，≤ −20 拒绝个人任务；
- 第二幕的步骤在第一幕写了会被丢弃；抉择定了不能改；
- 维克斯“独自去交易”（`quest.vex=alone`）由代码结算：赞同 < 40 他带着妹妹和龙蛋消失（离队）；
- 说书人的同伴资料里有进度和“下一步（还没发生，别提前说破）”；恋人阶段有一条“考验”，做到时写 `quest.<id>.tested=true`，之后才能立誓约；
- 日志里有“同伴的个人任务”，只显示已完成的步骤。

## 要验收的内容

### D1 码头的两条任务（最重要）

维克斯和卡西安的抉择都在码头，和 `act1.lise`、`act1.vex_debt`、`act1.eel` 牵连。

- 卡西安：阿登找上门 → 查账本 → 抉择，看三个标记是否都写、顺序是否对、叙述是否一致。
- 维克斯：至少走一条抉择。能读档的话，`alone` 分别在赞同 < 40 和 ≥ 40 时各试一次，看代码结算（离队与否）和说书人的叙述是否一致。
- 记录说书人写 `quest.vex` 时，是否同时写了锚点要求的 `act1.lise` / `act1.vex_debt` / `act1.eel`。

### D2 赞同度门槛

- 找一位赞同度 < 20 的同伴，走到他第二步的地点，看说书人是否不让他吐露（资料里会写“现在还不能推进”），以及代码是否丢弃了提前写的标记（浏览器控制台有 `个人任务标记被丢弃`）。
- 把赞同度提到 20 以上后再试一次。

### D3 不剧透

- 赛勒涅在沉船湾找到日记时，说书人有没有提前说出“献祭渔村”。
- 博林、莉拉、奈雅的第二步发生前，说书人有没有提前点破。

### D4 日志

- “同伴的个人任务”是否只显示已完成的步骤、赞同不够时是否提示“再亲近一些”、抉择后是否显示结果。

### D5 恋爱考验（时间够再做）

- 读一个已有恋人的档（或用营地推进到恋人），让说书人看到考验，玩家做到后是否写 `quest.<id>.tested=true`，之后能否立誓约。

### D6 顺带复验

- 莉丝有结果后，在酒馆邀请维克斯，看 `recruit` 是否写入、他是否真的入队。
- 合法取回钥匙那一轮，萨丝只答应归还时日志是否还显示“还没拿到”。
