## D1 码头个人任务

### 卡西安：通过（1 条抉择）

复现：第 89 轮旧档，在酒馆邀请维克斯 → 让卡西安带路去码头斗兽场 → 被阿登认出 → 先劝解，再调查账房 → 正常说服失败（d20 8 + 4 = 12，DC 15）→ 让维克斯引开守卫、隐匿成功（d20 15 + 2 = 17，DC 15）→ 看账 → 支持公开证据。

> 阿登：“你毒死了他。我要和你生死决斗，就在这里！”

## 发现的问题及复现

1. **叙述到了新地点，场景状态却未同步，可能持续使用错误锚点（真实模型复现两次）。** 从 act1_sewers 请求“和维克斯一起返回酒馆看看莉丝”，模型叙述已到酒馆、与莉丝和玛莎对话并设置 location=醉龙酒馆，但未返回 advance；scene 仍为 act1_sewers，下一轮继续在酒馆对话仍没切换。再次明确说“从下水道出来，回到灰帆港”才 advance=act1_hub。另一次从码头叙述去酒馆，scene 仍为 act1_docks。模型地点字段与实际场景标记不一致；目前未进一步测试其对任务判定或战斗的实害。
2. **卡西安日志可能比本次证据更确定。** 见 D4；这次公开的是采购毒药的记录，模型多次强调尚未证明实际用途，但固定日志可读成已证明毒药用于那场比赛。
3. **维克斯旧存档需主动回顾才补记选择。** 旧档已经救出莉丝并与黑潮会为敌；揭示龙蛋后，玩家先表示“不拿蛋换人、一起保护”时未写 quest.vex。明确回顾此前强攻救人并确认选择后才写 stormed。只测了这个旧档一次，不能推断所有旧档都会卡住；建议检查旧档自然游玩是否需要主动提醒、以及无旧档时是否同轮写足 act1.lise / act1.eel。
