## 怎么测、怎么发布

```bash
node --test tests/game-logic.test.mjs
node --test tests/local-server.test.mjs
node tests/combat-sim.mjs --runs 300
node tests/make-test-saves.mjs
```

- 最后一条会重新生成 `tests/saves/` 里 9 个停在关键位置的测试存档，给真实模型定点复验用。改了场景或标记后要重跑。
- **推送**：`git -c http.proxy=$HTTPS_PROXY -c https.proxy=$HTTPS_PROXY push origin main`。
- **同步 claude.ai 页面**：用 Artifact 工具发布 `index.html`，`url` 填上面那个链接（同一会话里发布过可以省略）。不传 `capabilities` 会保留现有的 `sample` 和 `downloads`；有新立绘时用 `files` 一起传。偶尔报 SSL 或审核错误，原样重试一次就好。

## 改代码的小经验

- `index.html` 很大，用 Python 脚本做精确替换，每处先断言只出现一次。
- 脚本要用 Write 工具写成 `.py` 文件再跑：文件头加 `# -*- coding: utf-8 -*-`，运行时加 `PYTHONIOENCODING=utf-8`。heredoc 里带“①”这类字符或反斜杠会出错。
- `git merge --no-commit` 刚结束时，立刻写 `index.html` 偶尔会报 `OSError: Invalid argument`，重跑一次就好。
- 支线的 `goal` 是给说书人看的（可以写答案），`task` 是任务日志里给玩家看的，写线索时别在 `task` 里说破答案。
- 同伴对手戏（`pair`）现在也能带 `when`；最后一夜的告别用 `kind: "farewell"`；插曲场景用 `interlude: true`。做法见 README。
