## 改代码的小经验

- `index.html` 很大，改的时候用 Python 脚本做精确的字符串替换（每处先断言只出现一次）。在 Windows 上写 Python 文件要带 `# -*- coding: utf-8 -*-`；heredoc 里的 `\n` 会被吃掉，带反斜杠的内容用 Write 工具写成 `.py` 文件再跑。
- 推送：`git -c http.proxy=$HTTPS_PROXY -c https.proxy=$HTTPS_PROXY push origin main`（代理端口会变，以环境变量为准）。
- 新增的常量如果在 `SYSTEM` 这类加载时就会求值的模板字符串里用到，要定义在它前面，否则会报 “before initialization”。
