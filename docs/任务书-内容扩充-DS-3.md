## 任务 D8：勇气试炼——按玩家背景的恐惧幻象

现在第一重试炼的锚点只写了“玩家的幻象由他的背景决定（具体写）”，全靠说书人现编。数据写在 `const TRIALS = { fears: {}, secrets: {} };` 的 `fears` 里（在 `index.html` 里搜 `const TRIALS`），按玩家背景的 id 写 8 段：

```js
const TRIALS = {
  fears: {
    soldier: { vision: "幻象的处境：玩家看见什么、谁在那里、幻象想逼他承认或放弃什么", ways: "两三种过关的办法和检定，例如“说出当年的真话（无需检定）、感知 DC 15 识破幻象、让一位同伴伸手把他拉出来”" },
    // urchin、sage、noble、acolyte、entertainer、sailor、outlander
  },
  secrets: { ... },
};
```

- 8 个背景：`soldier` 士兵、`urchin` 街头儿童、`sage` 学者、`noble` 贵族、`acolyte` 侍僧、`entertainer` 艺人、`sailor` 水手、`outlander` 弃徒（看 `BACKGROUNDS`，每个背景有“灵感条件”，可以参考它定这个人最在乎什么）。
- 玩家角色是玩家自己捏的，**不要替玩家定死过去**：幻象写成“一个通用的、这个背景的人多半经历过的恐惧”，留出让说书人按玩家之前说过的话改写的余地（例如“如果玩家提到过家人……”）。
- `ways` 至少两种，一种可以不靠检定（靠信念和行动），一种靠检定（写技能和 DC，DC 13～16）。也可以写失败的代价（比如失去一点龙化值之外的东西：一段记忆变模糊、同伴看见了他最狼狈的样子），但不要写数值奖惩。
- 说书人在这一场的提示词里会看到：“【勇气试炼的素材】玩家的背景是 X。幻象：……。过关的办法（可以有别的）：……”。

## 任务 D9：真相之厅——每位同伴的秘密

第二重试炼要每位同伴说出一个秘密，赞同度低于 20 的会先拒绝，要玩家说服。写在 `TRIALS.secrets` 里，六位同伴各一段：

```js
  secrets: {
    selene: { refuse: "赞同不到 20 时，她怎么拒绝、拒绝背后在怕什么、怎么样才说服得了她", tell: "她肯说时，说出的秘密是什么、说的时候的样子、其他同伴可能的反应" },
    // vex、kassian、borin、lyra、naia
  },
```

- 秘密以同伴资料（`COMPANIONS` 的 `secret`）和设定集角色卡为准，但**要看时机**：到神殿时，有些秘密已经在个人任务里揭开了（例如维克斯的龙蛋、卡西安打死过好友、博林的哥哥达林还活着）。所以 `tell` 要写两层：“若这件事队伍已经知道了（个人任务做到哪一步可以看 `QUESTS`），他说的是更深的一层：……；若还没人知道：……”。
- **赛勒涅的秘密是她自己都不知道的**（她是容器），不能让她在这里说出来。她的 `tell` 写一件她自己知道、但从没说过的事（比如骑士团覆灭那一夜她在做什么、她对等待了一百年的真实感受）。
- 奈雅的真名和千面母的事，看 `quest.naia.name` 有没有做；不要让她在这里交出真名（那是她个人任务的抉择）。
- 说书人在这一场看到：“【真相之厅的素材】名字：（赞同不到 20，先拒绝）refuse；被说服之后：tell；……”（只列在场的同伴）。

## 任务 D10：老鳗的事件链

上一轮四条链选了伊芙，没做老鳗。补一条 **3 步**的链：老鳗和黑潮会的下场。

- 用支线的 `need` 串起来，格式和上一轮一样（`SIDE` 里加条目）。建议第一步在第一幕的码头一带（`act1_docks`、`act1_docks_casino`），第二步在第二幕（黑潮会的走私船在群岛一带跑，见上一轮的走私客皮特），第三步在第三幕的避难所或燃烧的码头。

- 老鳗是黑潮会首领、主线 NPC，**不能在支线里杀掉他**（卡西安的个人任务里有让卡西安杀死老鳗的抉择，那条由个人任务管）。如果 `quest.kassian` 是 `killed_eel`，老鳗已经死了，第三步要能读得通，或者用 `need` 让它不出现。
